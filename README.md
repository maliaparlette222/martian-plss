# martian-plss 🚀

A public project portfolio by **Malia Parlette** — freshman at the University of Maryland (University Honors), majoring in Aerospace Engineering (Class of 2030).

I'm learning real engineering by building. Each project here is a small, visual simulation of one real concept behind flight and spaceflight — orbital mechanics, the rocket equation, airfoil lift, projectile motion with drag. One concept per project, and honest about what's simulated: these are visualizations of real physics, not claims of real engineering analysis.

**For internships:** this repo is my build log. Every project gets a write-up in the same template — what it does, what it teaches, how it was built, the prompt used to build it, and what broke along the way.

## How projects are structured

Every project lives in `projects/<project-name>/` and follows the same template ([project-template/README.md](project-template/README.md)):

1. **What it does** — description + demo (GIF for small demos; unlisted YouTube embed for bigger ones)
2. **What it teaches** — the concept explained in my own words
3. **How it was built** — tools used, key code, decisions made along the way
4. **The build prompt** — the polished AI prompt used, written so someone else could reuse it
5. **What broke and what I learned** — the honest part

## Repo conventions

- Demos stay lean: small animations as GIFs in the project folder; anything bigger goes on YouTube (unlisted) and gets embedded in the write-up.
- No API keys, no secrets, no personal info — ever. See `.gitignore`.
